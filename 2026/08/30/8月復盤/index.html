8月復盤

2026-08-30 #Daily#Monthly

最後一個暑假也是最挫折的暑假

這個暑假從六月開始早就規劃好了行程，但直到暑假為止有成功的部分幾乎微乎其微

  • 16周 | 演算法期末考、資料庫系統期末考、VR 專題、APP 專題
  • 17周 | Java 上機考、動畫專題
  • 18周 | 資料庫系統專題
  • 19周 | 報復性休息
  • 20周 | 找工作
  • 暑假 | 補習班一對一家教 → 教具設計比賽 → 開始實驗室計畫 → AR2VR比賽 → 問題解決松
  • 9月 | 開學 → 準備應科所考試

輔了資科系原本以為自己未來的志向會跑到資工，但我發現自己對程式的熱情往往是來自於前端可與他人互動的部分而非資安、資料庫、AI這些具市場需求的能力，更別說是硬體。

當初讀研的主要目標就是: 台科應科丙組，今年仍然只有考試入學 ( 但只要書審 )，所以就想著一邊做 VR 研究一邊找未來的研究目標，但從七月開始一切就…

一對一家教

教的是一個小五生小六的女生，三角形面積公式、分數與小數換算、容量與體積等對於我而言在學習的途中並未遇到挫折，然而對於她來說不是如此。
為了符合她的程度，每題在講解時一步步帶他拆解數字代表的意思，找出公式所需的數字，上課時也會看他平常插畫的內容、上的才藝課來嘗試找話題，但都沒有什麼共鳴…

第二周結束的周末，收到了補習班的來訊，家長認為我的教學風格不適合該名學生，因為無法和家長對接我只能向補習班那說明上課的情況、我的風格與自己可以改進的地方，但一切都是徒勞。那時手頭上還有一個國中學生，只上了一堂課、第二周開始請假，第三周就在我失去國小學生教學工作的同時，此國中學生的課也一併被砍掉，我不清楚原因，得到的回覆也只有: 後續有適合的學生會再介紹，然而直到今日我仍被冷凍。

實驗室

五月底就詢問好了教授，當初的回覆也是 7 月底會開始專案，然而 7 月中詢問是否已經開始實驗或是有群組要加入，得到的回覆是: 下列題材哪些有興趣? 然而那些題材與先前五月時教授的研究目標不競相同，回覆完有興趣的題目後教授回了貼圖就失去了下文，八月初再次詢問，得到的回覆是: 人員籌備中，原本7越是: 實驗室、比賽、打工，三者的結合然而我只剩比賽可做，其餘兩者都在我無法控制的情況下失去了

( 喔對了，八月底詢問終於得到近期要開始開會的回覆 )

失去了工作與實驗室，花了兩周把教育比賽的程式、UI、企劃都用完後我開始求職，但此時我的身心狀態不太好，多半原因是因為被迫失業的因素，當你付出的努力無法與收穫打平，甚至直接被他人一竿子打翻，原本是對結局感到詫異，後來是開始無限檢討自己: 我是不是真的教得很差 這句話不斷在我心裡徘迴。

2040 School

再悲傷的期間，我再 Thread 滑到了這個非營利的新聞媒體在招募，當初想報名的原因有兩個

  1. 非營利媒體在我眼中蠻吃力不討好的，我想了解是什麼促使他們能持續經營? 尤其 Instagram 是很重影音的平台，純靠文字的貼文勢必沒有什麼流量，如何去克服流量只為了專注報導彼此眼中的真相，是我想要去理解的
  2. 我好像好久沒有團體的感覺，上大學後為了維持兩邊的功課，而且每天揹著平板、筆電在公車、在捷運上來回通勤每次都要 1 個小時，讓我真的沒什麼心力參與課外活動，我想要有機會可以去與外面的人互動，也想了解他們參與的初衷

參加 2040 算是唯一順利的事情，也可能是美宣報名的人本就較少才幸運上岸，上了培訓課我很認同的觀點是:

想要理解真相，除了去搜索已知的資訊外，實際走訪並與他人互動才能真正去理解; 有了感受與自身的視野我們才能寫好一篇文章

這件事也讓我想到，大學以來做了一些和教育性質相關的工作或專題

  • 青春痘知識宣導的桌遊設計
  • 演算法入門遊戲
  • VR 恐龍挖掘遊戲
  • SDGS 相關的 VR 互動場景遊戲( 我只能說那個平台有夠難用，不能共編、很容易拖曳到已經擺放好的物件、自由度低… )
    甚至後來實驗室的主題也是結合 VR 和 半導體來運用到小學現場中(現在的小朋友真的辛苦了)

但我真的設計出適合小朋友的作品了嗎? 我的目標客群都寫國中小生，但實際上我服務的對象都是評審和老師，因為這個想法我開始投遞了新的工作

康軒-數位專案助理

很幸運地從投遞履歷 → 一階書面問題回答 → 二階實體面試，進入到最終面試的好像只有我和另一名面試者就當場面試官的口語判定。當下我認為自己在問答、專案介紹、提問都表現得宜，主要的數位專案負責人也針對我的專題進行提問，整體氛圍良好，面試完也得到最快明天晚上就會有結果的資訊。

抱著期待的心情回家，隔天是個雨天心情從期待到緊張，不停的刷新電子郵件，約莫晚上11點終於收到了回覆，是封感謝信。就如同上次失業一樣，原本是釋懷到開始自責，我又開始迷失了，既失去了工作，當下實驗室又不能保證何時會開始，手頭上只剩畢業專題和另一個比賽( 喔對了當初還跟教授說如果有應徵上會退實驗室，所以當初拖了一點時間才告知面試沒上，因為覺得很丟臉 )，看著身旁的人在實習、校園大使，而我只能在家刷著 104、想著如何改進畢業專題、做著比賽就覺得自己很廢…

職掘-課程企劃實習生

當初在投康軒之前原本就想投遞，但心裡因為先前補習班的是件讓我仍有芥蒂自己是不適合這種營隊性質的團隊，康軒面試失敗後，剛好 2040 的培訓課是創辦人主講，看了他提供的 IG 連結到了在裏頭工作的員工的個人檔案，看到他對於工作內容的分享，以及眼神有光的樣子是我想要追求的目標，我開始深入挖掘此企業的社群，創辦人有段影片促成了我想要投遞的契機

你有沒有一件事情是即使他很累，你仍然會想要堅持下去

其實對這件事我一直沒有明確的目標，對於人生我還在不斷探索，唯一確定的是 我很享受別人因為我的作品而觸發情緒的那瞬間、我很享受大家為了同一目標犧牲自己時間來做好一件事的時刻，上次有這種感覺大概是高中最後一次大隊接力，之前從學校帶領學生回安親班時小孩跟我分享他們生活的時候，都讓我有幸福的感覺

很幸運地通過二階書審，又來到了最終階段但這次的得失心就沒那麼重了，畢竟這個職位從6月開始徵應該已經有適合的人才，就當作是增加面試經驗的途徑。

喔對了問題解決松後來覺得活動方向和自己不太適合，而且熬夜會讓我的身心情況變糟，所以就取消報名了，現在就專注在

  • 畢業專題
  • 2040 美宣
  • 實驗室專案

如果有幸面試上職掘我的大四會非常充實，且看且走吧!
