搶救多益大作戰 - 詞性

2026-08-31 #TOEIC#English

多益倒數 20 天，救救孩子吧 _(´ཀ`」 ∠)

詞性 搭配 備註
名詞 a(n) / the + N
形容詞 adj + N 用來修飾名詞，看到題目時需檢查修飾的是 動詞 還是 名詞
副詞 V + adv 可修飾 動詞、形容詞、副詞、句子

名詞

Be + The N of...
  • The necessity of learning English.
  • The necessary of learning English.
  • It is necessary to learn English.
  • The object(目的) of their expedition was to discover the source of the River Nile.

介係詞搭配

單字 句子
interest interest in sth
demand demand for sth
need need for sth
reason reason for sth
solution solution to sth
access access to sth
increase increase in sth
decrease decrease in sth
effect effect on sth
impact impact on sth
responsibility responsibility for sth
effort in an effort to V
problem have a problem with sth
advantage take advantage of sth
  • have difficulty / trouble / a hard time + Ving

形容詞

常見形容詞使用方式

Be + Adj

The product is successful.

S + 連綴動詞 + Adj
  • seem: The manager seems satisfied.
  • become: The weather became colder as night fell.
  • appear: The solution appear simple.
  • look: The dessert looks delicious.
  • feel: I feel exhausted after working.
  • sound: The idea sounds interesting.
  • remain: Please remain calm during an emergency.
  • stay: Exercising regularly helps you stay healthy.

介係詞搭配

單字 句子
responsible be responsible for N / Ving
familiar be familiar with N
interested be interested in N / Ving
aware be aware of N
capable be capable of N / Ving
eligible be eligible for N
similar be similar to N
different be different from N
satisfied be satisfied with N
contingent be contingent on / upon N 視…而定
subject be subject tp sth 遭受、視…而定
accordance in accordance with sth 依照
  • be contingent on = depend on = be dependent on / upon

副詞

  • The manager carefully reviewed the report. - 修飾 review

  • The product is extremely popular. - 表示程度

  • Fortunately, everyone arrived on time.

動詞

  • 助動詞(can / may / will / could / might / would / should) + V

  • 及物動詞: 不須額外用介係詞即可接受詞

    單字 句子
    discuss discuss the issue
    attend attend the meeting
    contact contact the client
    reach reach an agreement
    enter enter the building
    approach approach the manager
    mention mention the problem
    answer answer the question
    explain explain the question
    oppose oppose sth
    obey obey sth

  • 不及物動詞

    單字 句子
    depend depend on + N
    participate participate in N
    apply apply for / to N
    respond respond to N
    belong belong to N
    consist consist of N / Ving
    result result in / from / of
    arrive arrive at / in N
    comply comply with N
    agree agree with N
    refer refer to N
    specialize specialize in N
    contribute contribute to N
    apologize apoligize for N / Ving
    intend be intended for N
    intend be intended to V
    lack lack of N
    reply reply to N
    • depend on = be dependent on = dependable
    • explain + 受詞 / explain to sb about sth
    • remind sb of sth / to V（提醒）
      • The prison has been turned to a museum to remind visitors of the spirit of independence.
    • Suggest + N: Suggest a solution
    • Suggest + Ving: Suggest changing the schedule
    • Recommend + N
    • Recommend + Ving
    搭配 翻譯 句子
    A results in A 導致 B Poor management resulted in higher costs.
    B results from A B 起因於 A The problem resulted from poor management.
    搭配 翻譯 句子
    apply for N 申請 We’ve applied for a grant to get funding for the project.
    apply to N 適用於／向……申請 Mandy applied to join the police.
    搭配 翻譯 句子
    reply to N 回覆
    respond to N 回覆
    answer N 回覆
    搭配 翻譯 句子
    be intended for N 設計給 This program is intended for beginners.
    be intended to V 目的在 This program is intended to help beginners.
    搭配 翻譯 句子
    stop by 順道拜訪
    stop over 中途停留

使役動詞

  • ask / tell / allow / require / make sb to V
    • The manager asked employees to attend.

V + to V / to Ving / V + V-ing

  • to V

    • want to go
    • need to finish
    • plan to expand
    • decide to attend
    • hope to receive

  • to Ving

    • look forward to Ving
    • be accustomed(習慣) to Ving
    • be commited(承認) to Ving
    • object(反對) to Ving

  • V + Ving

    • enjoy Ving
    • avoid Ving
    • consider Ving = consider for N 考慮
    搭配 翻譯 句子
    consider + N / Ving 考慮 She is considering moving to the UK
    consider + O + (to be) N / Ving 視為 Many people consider this park a perfect place
    be considered (to be) N / Ving 視為 He is considered (to be) the best athlete

連接詞 / 名詞子句

搭配 用法
because + S + V 因為
because of N / Ving 因為
although + S + V 雖然
despite + N / Ving 儘管
in spite of + N / Ving 儘管
while + S + V 當… / 然而
during + N 在…期間

However

  • However, S + V = Although S + V
    • However, the company decided to continue.
  • however + adj / adv
    • however difficult it is = no matter how difficult it is

介係詞

  • at + 準確時間
    • at 9:00
    • at night
  • on + 日期 / 星期
    • on Friday
    • on my birthday
    • on weekdays
  • in + 月 / 年 / 季節 / 長時間
    • in the morning
    • in summer
    • in 2026
    • in January
  • by + 截止時間
    • Submit the report by Friday.
  • until + 持續到某時間
    • The office will remain open until Friday.
  • durning + N(時間 / 活動)
    • durning the meeting / summer
  • while + S + V
    • while I was working
