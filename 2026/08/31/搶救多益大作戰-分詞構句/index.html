搶救多益大作戰 - 分詞構句

2026-08-31 #TOEIC#English

核心目標 : 將完整的副詞子句簡化、去掉重複主詞與連接詞

主動 → V-ing

原本:

Because he was tired, he went to bed early.

改

Being(主動) tired, he went to bed early.

被動 → V-p.p.

原本:

Because it was written in English, the book is easy to read.

改

Written(被動) in English, the book is easy to read.

去連接詞

肯定句

原本:

We will go picnicking tomorrow if weather permits.

改

We will go picnicking tomorrow, weather permitting.

否定句

原本:

The teacher was not happy about the student’s performance, so the teacher asked him to try again.

改

Not (being) happy about the student’s performance, so the teacher asked him to try again.
